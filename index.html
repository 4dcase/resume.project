This resume website

Designed and coded from scratch as my web development course project. No frameworks and no JavaScript — just semantic HTML and one stylesheet.

  • Semantic HTML5 structure
  • Flexbox + Grid layout
  • Responsive across screen sizes
  • CSS-only tap-to-flip cards

Design notes

Built around a five-color palette: near-black, hot pink, cyan, violet and silver. Motion is kept slow and subtle so the page stays calm while still feeling alive.
